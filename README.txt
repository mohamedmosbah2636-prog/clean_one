كلين وان - موقع خدمات التنظيف
================================
طريقة التشغيل:
1) فك ضغط الملف.
2) افتح مجلد clean_one_website.
3) افتح index.html في المتصفح.

للنشر:
ارفع محتويات المجلد كاملة إلى الاستضافة أو إلى GitHub Pages / Netlify.
لا تنقل index.html وحده؛ يجب رفع مجلد assets معه.
